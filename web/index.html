Bluetti ESP32 ControllerWeb installer

Flash it from your browser

A touch screen for your BLUETTI power station: charge, time remaining, power in and out, and an AC switch. It talks to the station over Bluetooth, with no app or Wi-Fi.

Your browser can't talk to USB devices. Open this page in desktop Chrome or Edge.

USB access needs a secure page (https).

Firmware version __VERSION__, built from the latest code on GitHub.

What you need

  1. A Waveshare ESP32-S3-Touch-LCD-3.5 (SPI version).
  2. A USB-C data cable (some cables only charge).
  3. Desktop Chrome or Edge.

Installing

  1. Plug the board into this computer.
  2. Press Connect & install and pick the board's USB port (it usually mentions "USB JTAG" or "ESP32").
  3. Choose whether to erase the device. Erasing forgets the saved station; leave it off when updating.
  4. Wait about a minute. The board restarts on its own when done.

No port shows up? Unplug the board, hold its BOOT button while plugging it back in, then try again.

First run

The board looks for stations nearby. With one in range it connects straight away; with several, tap yours in the list and it remembers it. Tap AC to switch the inverter, swipe to change stations.
